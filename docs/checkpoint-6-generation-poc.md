# 체크포인트 6 콘텐츠 생성 PoC

## 공급자와 호출 경계

- 서버 전용 OpenAI SDK `7.1.0`, Responses API, Structured Outputs를 사용한다.
- 모델은 `gpt-5.6-terra`로 고정하며 모델 fallback을 사용하지 않는다.
- 일반 로컬 실행은 `OPENAI_API_KEY`가 없으면 호출 전에 실패한다. fake provider는 Playwright가 명시적으로 주입하는 비운영 테스트 경로에서만 사용한다.
- SDK 내장 재시도는 0회다. 애플리케이션은 HTTP 429, 5xx, 연결 timeout/실패만 최대 한 번 재시도한다.
- 프롬프트는 근거 텍스트를 신뢰하지 않는 데이터로 구분하며, 등록한 공식 근거 밖의 사실을 만들지 않도록 지시한다.

## 비용과 사용량

2026-07-29 공식 표준 단가(입력 $2.50/백만 토큰, 출력 $15/백만 토큰)를 적용한다. 최대 입력 40,000 및 출력 12,000 토큰의 보수적 사전 비용은 `$0.28`이며 작업 상한 `$0.60`보다 낮다. 각 호출과 재시도 전에 남은 입력·출력 토큰과 비용을 다시 검사한다. API가 반환한 실제 입력·출력 usage와 그 usage로 계산한 보수적 비용을 별도로 저장한다.

| 구분 | 상한 |
| --- | ---: |
| 로컬 일일 작업 | 3건 |
| 동시 작업 | 1건 |
| 작업 입력 | 40,000 토큰 |
| 기획안 출력 | 3,000 토큰 |
| 초안 출력 | 9,000 토큰 |
| 작업 총 출력 | 12,000 토큰 |
| 작업 비용 | $0.60 |

## 키 취급

`OPENAI_API_KEY`는 `.env.local`에만 입력한다. `NEXT_PUBLIC_` 접두사를 붙이지 않으며 DB, Git, 브라우저 응답, 로그 및 오류 메시지에 값·일부 문자열·길이·접두사를 기록하지 않는다. 키 존재 확인도 값이 출력되지 않는 방식으로만 수행한다.

## 현재 검증 경계

6C 준비 검증은 OpenAI 클라이언트를 메모리 mock으로 대체하므로 외부 API 요청과 비용이 없다. 실제 통합 검증은 사용자가 로컬 키 입력을 확인한 뒤 Virtual 브랜드 1건에 대해서만 별도로 수행한다.
