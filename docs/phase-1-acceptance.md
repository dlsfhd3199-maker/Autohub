# 1단계 MVP 인수 체크리스트

## 구현 요약

- CP1: Next.js·TypeScript·pnpm·Vitest·Playwright 기반
- CP2: Supabase Auth, 조직·역할·브랜드, RLS, 감사 로그
- CP3: 브랜드·담당자·배정, 검색·필터·페이지네이션
- CP4: 블록 스튜디오, 자동 저장, 충돌 처리, 버전 이력·복원

## 인수 확인

- [ ] 관리자·AE·광고주 로그인과 권한 확인
- [ ] AE 배정·미배정 브랜드 격리 확인
- [ ] 광고주 읽기 전용 및 직접 API 변경 차단 확인
- [ ] 브랜드 생성·수정·보관과 담당자 배정 확인
- [ ] 콘텐츠 검색·필터·페이지 이동 확인
- [ ] 5초 자동 저장과 새로고침 복원 확인
- [ ] 다중 탭 충돌 복구 확인
- [ ] 버전 생성·이력·복원·불변성 확인
- [ ] 360px 모바일과 키보드 포커스 확인
- [ ] 전체 CI·로컬 검증 통과 확인
- [ ] 운영 DB·배포·도메인이 생성되지 않았음을 확인

병합, 원격 Supabase, Vercel 배포와 운영 도메인은 별도 승인 사항이다.
