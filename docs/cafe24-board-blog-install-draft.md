# Cafe24 블로그 전용 게시판 설치 가이드 초안

> 실제 Cafe24 테스트몰에서 검증하기 전의 초안이다. 운영몰에 직접 적용하지 않는다.

## 적용 원칙

- 연결 유형은 `cafe24-board-blog`로 구분한다.
- Content Hub의 명시적 불변 버전만 발행 대상으로 삼는다.
- 자동 저장 draft와 working draft는 게시판에 전달하지 않는다.
- 공통 스킨 전체를 자동 변경하지 않는다.
- 복제 스킨과 블로그 전용 게시판 템플릿만 수정한다.
- 연결을 해제해도 기존 게시물은 유지하는 방향을 기본 검토안으로 둔다.
- 게시물 API 본문에는 정제한 본문 HTML만 전달하고, canonical과 JSON-LD는 상세 템플릿 적용 후보로 분리한다.

## 1. 적용 전 백업

1. 현재 사용 중인 PC·모바일 스킨 이름과 적용 시각을 기록한다.
2. 스킨을 복제하고 `Virtual Blog Preview`처럼 테스트임이 분명한 이름을 사용한다.
3. 기존 메뉴·게시판 설정과 주요 페이지를 캡처한다.
4. 수정 전 템플릿 파일을 별도로 내려받아 보관한다.
5. 운영 스킨에는 어떤 변경도 적용하지 않았는지 재확인한다.

## 2. 전용 게시판 생성

1. 테스트몰 관리자에서 블로그 전용 게시판을 만든다.
2. 게시판 식별자는 브랜드 연결 설정의 `default publishing target`으로 관리한다.
3. 글쓰기·수정·삭제 권한은 관리자 전용으로 제한한다.
4. 목록과 상세 열람은 비회원과 일반 고객에게 허용한다.
5. 댓글·첨부·비밀글 등 PoC에 필요하지 않은 기능은 비활성화한다.
6. 커넥터에는 게시판 조회와 게시물 작성·수정에 필요한 최소 권한만 부여한다.

## 3. PC 블로그 메뉴

1. 복제한 PC 스킨의 상단 메뉴 파일을 연다.
2. 기존 상품·기획전 메뉴와 같은 계층에 `블로그` 항목을 추가한다.
3. 링크는 블로그 전용 게시판 목록 URL을 사용한다.
4. 블로그 목록·상세에서는 현재 메뉴에 활성 상태를 표시한다.
5. 공통 메뉴 외 다른 PC 스킨 파일은 변경하지 않는다.

## 4. 모바일 블로그 메뉴

1. 복제한 모바일 스킨의 주 메뉴 또는 드로어 메뉴 파일을 연다.
2. `블로그` 항목과 동일한 게시판 목록 URL을 추가한다.
3. 360px에서 메뉴, 카드, 본문, 표, CTA에 가로 넘침이 없는지 확인한다.
4. PC 메뉴와 모바일 메뉴를 각각 독립적으로 원복할 수 있게 변경 파일을 기록한다.

## 5. 목록 전용 템플릿

- 카드형 콘텐츠 목록을 사용한다.
- 카테고리, 제목, 요약, 게시일, 수정일을 표시한다.
- 썸네일이 없을 때는 브랜드 기본 자리표시자를 표시한다.
- 페이지네이션과 콘텐츠 없음 상태를 제공한다.
- Content Hub의 draft와 working draft는 목록 API에 포함하지 않는다.

## 6. 상세 전용 템플릿

- 제목, 카테고리, 게시일, 수정일과 확정 버전을 표시한다.
- 핵심 답변, 본문, 표, 체크리스트, FAQ, 출처, CTA를 렌더링한다.
- 관련 콘텐츠와 관련 상품 영역을 제공한다.
- 게시물 API 본문에 JSON-LD가 보존된다고 가정하지 않는다.
- canonical, Article, BreadcrumbList, 조건부 FAQPage는 상세 템플릿 또는 별도 메타 주입 계층에서 처리한다.
- 실제 Cafe24 HTML 정제 후에도 허용되는 태그·속성을 테스트몰에서 확인한다.

## 7. 복제 스킨 미리보기 검수

1. 복제 스킨 미리보기 URL에서만 검수한다.
2. PC와 모바일 메뉴가 블로그 게시판으로 이동하는지 확인한다.
3. 비로그인 브라우저에서 목록과 상세가 열리는지 확인한다.
4. 같은 콘텐츠의 새 확정 버전을 발행했을 때 기존 게시물이 수정되는지 확인한다.
5. 새 버전 확정 전 draft 변경이 게시판에 반영되지 않는지 확인한다.
6. 본문 HTML, 링크, 표, FAQ, 출처, CTA 정제 결과를 확인한다.
7. canonical과 JSON-LD를 HTML 원문에서 확인한다.

## 8. 즉시 원복 절차

1. 운영 스킨이 변경됐다면 즉시 이전 스킨으로 선택을 되돌린다.
2. PC·모바일 메뉴에서 추가한 블로그 항목을 제거하거나 이전 파일로 복원한다.
3. 블로그 전용 목록·상세 템플릿을 백업본으로 복원한다.
4. `cafe24-board-blog` 연결을 비활성화한다.
5. 연결 해제 시 기존 게시물은 자동 삭제하지 않는다.
6. 게시판을 삭제하지 말고 비노출 여부와 SEO 영향을 별도로 검토한다.

## 실제 테스트몰에서 남은 검증

- OAuth 권한 범위와 토큰 갱신
- 게시판 목록 조회 및 게시물 작성·수정 API 계약
- 동일 게시물 업데이트에 사용할 외부 게시물 ID
- Cafe24가 제거하거나 변경하는 HTML 태그·속성
- 상세 템플릿의 canonical·JSON-LD 주입 가능 위치
- PC·모바일 복제 스킨 미리보기 및 즉시 원복
- 운영몰 적용 승인 절차
